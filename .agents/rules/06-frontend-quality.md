# Frontend discipline
- Use React TypeScript for admin/owner/manager desktop/tablet and employee mobile screens; never invent POS.
- FE route/menu filters improve UX only. Backend must authorize every request.
- Display business date, selected branch, transaction status and clear provisional P&L labels.
- Include empty, loading, error, permission-denied, retry and slow-network states; keyboard and mobile accessibility.
- Integrate only against reviewed API contract; no mock data represented as actual posted finance.
