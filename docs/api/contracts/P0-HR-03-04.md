## 1. Domain Model & Business Invariants

### 1.1 Business Invariants (`BR-HR-02`, `TC-013`, `TC-017`)
1. **Payable Hours Approval (`HR-INV-01`):**
   - Giờ làm việc tính lương (`approved_minutes`) và ngày công tính lương (`payable_workdays`) là dữ liệu độc lập với GPS.
   - Mỗi bản ghi xác định duy nhất bởi `(employee_id, branch_id, work_date)`.
   - Các trạng thái (`status`):
     - `DRAFT`: Mới tạo hoặc lưu nháp.
     - `SUBMITTED`: Đã gửi chờ cấp thẩm quyền phê duyệt.
     - `APPROVED`: Đã được duyệt, khóa không cho chỉnh sửa tự do và là dữ liệu đầu vào trực tiếp cho Engine tính lương `P0-HR-05`.
     - `REJECTED`: Bị từ chối (kèm lý do).

2. **Quy tắc An toàn Nghiêm ngặt: Cấm Quản lý tự duyệt công của mình (`TC-017` / `HR-INV-02`):**
   - Quản lý cửa hàng (`branch.manager`) chỉ có quyền phê duyệt bảng công cho các nhân viên cấp dưới trong chi nhánh.
   - Khi thực hiện phê duyệt (đơn lẻ hoặc hàng loạt):
     - Hệ thống kiểm tra: Nếu nhân viên của bản ghi chấm công có `employee.user_id == current_user.id` (hoặc người duyệt chính là người thụ hưởng công):
       - Nếu người dùng chỉ có quyền `branch.manager`: **BẮT BUỘC TỪ CHỐI** với mã lỗi RFC 7807 `403 Forbidden` (`urn:mtms:error:self-approval-denied`).
       - Chỉ có Chủ quán (`branch.owner`) hoặc Quản trị viên (`system.admin`) mới có quyền phê duyệt bảng công cho Quản lý cửa hàng.
   - Khi phê duyệt, hệ thống tự động ghi nhận `approved_by = current_user.id`, `approved_at = now()`, và lưu vết `approval_note`.

3. **Chấm công hàng loạt theo ca (Bulk Timesheet Entry):**
   - Hỗ trợ Quản lý nhập nhanh giờ làm cho danh sách nhiều nhân viên làm việc trong cùng một ngày tại chi nhánh.

## 2. Database Schema (Flyway `V021`)

```sql
-- P0-HR-03 & P0-HR-04: Timesheet Entries

CREATE TABLE mtms.timesheet_entries (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    employee_id UUID NOT NULL REFERENCES mtms.employees(id) ON DELETE CASCADE,
    branch_id UUID NOT NULL REFERENCES mtms.branches(id),
    work_date DATE NOT NULL,
    raw_minutes INTEGER CHECK (raw_minutes IS NULL OR raw_minutes >= 0),
    approved_minutes INTEGER NOT NULL DEFAULT 0 CHECK (approved_minutes >= 0),
    payable_workdays NUMERIC(6,2) NOT NULL DEFAULT 0.00 CHECK (payable_workdays >= 0),
    source_type VARCHAR(24) NOT NULL DEFAULT 'MANUAL' CHECK (source_type IN ('MANUAL', 'IMPORT', 'AUTO')),
    status VARCHAR(20) NOT NULL DEFAULT 'DRAFT' CHECK (status IN ('DRAFT', 'SUBMITTED', 'APPROVED', 'REJECTED')),
    note TEXT,
    approved_by UUID REFERENCES mtms.users(id),
    approved_at TIMESTAMPTZ,
    approval_note TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE (employee_id, branch_id, work_date)
);

CREATE INDEX idx_timesheet_branch_date ON mtms.timesheet_entries(branch_id, work_date);
CREATE INDEX idx_timesheet_emp_date ON mtms.timesheet_entries(employee_id, work_date);
CREATE INDEX idx_timesheet_branch_status ON mtms.timesheet_entries(branch_id, status);
```

## 3. REST API Specification

### 3.1 `GET /api/v1/branches/{branchId}/hr/timesheets`
Lấy danh sách các dòng chấm công theo bộ lọc khoảng ngày, nhân viên hoặc trạng thái (hỗ trợ phân trang).

**Query Parameters:**
- `startDate` (ISO Date `YYYY-MM-DD`, optional)
- `endDate` (ISO Date `YYYY-MM-DD`, optional)
- `employeeId` (UUID, optional)
- `status` (`DRAFT`, `SUBMITTED`, `APPROVED`, `REJECTED`, optional)
- `page` (int, default 0)
- `size` (int, default 50)

**Response `200 OK`:**
```json
{
  "content": [

      "id": "110e8400-e29b-41d4-a716-446655440001",
      "employeeId": "770e8400-e29b-41d4-a716-446655440111",

      "positionName": "Pha chế",
      "workDate": "2026-11-19",
      "rawMinutes": 480,
      "approvedMinutes": 480,
```

### 3.3 `POST /api/v1/branches/{branchId}/hr/timesheets`
Tạo mới hoặc cập nhật thông tin chấm công cho 1 nhân viên trong ngày.

**Request Body:**
```json
{
  "employeeId": "770e8400-e29b-41d4-a716-446655440111",
  "workDate": "2026-11-19",
  "approvedMinutes": 480,
  "payableWorkdays": 1.00,
```

**Response `201 Created` / `200 OK`:** Trả về `TimesheetEntryDto`.

### 3.5 `POST /api/v1/branches/{branchId}/hr/timesheets/{id}/approve`
Phê duyệt giờ công tính lương.

**Request Body:**
```json
{
  "approvalNote": "Xác nhận đúng giờ làm thực tế"
}
```

**Ràng buộc bảo mật `TC-017`:**
- Nếu bản ghi thuộc nhân viên liên kết với tài khoản của người gọi API (`employee.user_id == current_user.id`), và người gọi **không phải là Chủ quán (Owner) hoặc Admin**:
  - Trả về `403 Forbidden`: `urn:mtms:error:self-approval-denied`.
- Nếu hợp lệ: chuyển trạng thái `status = 'APPROVED'`, ghi nhận `approved_by` và `approved_at`.

**Response `200 OK`:** Trả về `TimesheetEntryDto`.

---

### 3.6 `POST /api/v1/branches/{branchId}/hr/timesheets/bulk-approve`
Phê duyệt hàng loạt danh sách các dòng công.

**Request Body:**
```json
{
  "entryIds": [
    "110e8400-e29b-41d4-a716-446655440001",
    "220e8400-e29b-41d4-a716-446655440002"
  ],
  "approvalNote": "Duyệt công hàng loạt ca hôm qua"
}
```

**Ràng buộc bảo mật `TC-017`:**
- Bất kỳ dòng nào vi phạm điều kiện tự duyệt của Quản lý sẽ bị chặn hoặc báo lỗi `403 Forbidden` (`urn:mtms:error:self-approval-denied`).

**Response `200 OK`:**
```json
{
  "approvedCount": 2,
  "failedCount": 0
}
```

---

### 3.7 `POST /api/v1/branches/{branchId}/hr/timesheets/{id}/reject`
Từ chối dòng chấm công.

**Request Body:**
```json
{
  "rejectionReason": "Sai ca làm việc, chưa thấy check-in thực tế"
}
```

**Response `200 OK`:** Trả về `TimesheetEntryDto` với trạng thái `REJECTED`.

## 4. RFC 7807 Error Responses

| Mã lỗi HTTP | Type URI | Lý do |
| :--- | :--- | :--- |
| `400 Bad Request` | `urn:mtms:error:invalid-timesheet-data` | Số phút hoặc ngày công âm; dữ liệu ngày không hợp lệ. |
| `403 Forbidden` | `urn:mtms:error:self-approval-denied` | **`TC-017`**: Quản lý không được phép tự phê duyệt giờ công của chính mình. |
| `403 Forbidden` | `urn:mtms:error:forbidden` | Người dùng không có quyền truy cập chi nhánh. |
| `404 Not Found` | `urn:mtms:error:timesheet-not-found` | Không tìm thấy dòng chấm công theo ID. |
| `409 Conflict` | `urn:mtms:error:timesheet-already-approved` | Bản ghi đã được duyệt không thể sửa nháp trừ khi được yêu cầu đặc biệt. |
