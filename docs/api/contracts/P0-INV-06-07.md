### 2.3 Inventory-to-COGS Period Read Model (P0-INV-07 / TC-020)
#### `GET /api/v1/branches/{branchId}/inventory/cogs-report`
- **Scope:** `@branchAuth.hasBranchAccess(#branchId)`
- **Query Params:** `startDate`, `endDate` (or `month=2026-11`)
- **Business Math (TC-020 No Double Cost Invariant):**
  - `periodPurchasesTotal`: Total goods received from suppliers in period (posts to Payables, NOT COGS).
  - `periodCogsTotal`: Sum of absolute `MANUAL_ISSUE` values in period (Giá vốn hàng bán).
  - `reconciliationFormula`: $\text{Ending Stock} = \text{Beginning Stock} + \text{Purchases} - \text{COGS}$.
- **Response `200 OK`:**

## 3. Strict RFC 7807 Error Code Catalog

| HTTP Status | `type` URI | `title` | Description |
| :--- | :--- | :--- | :--- |
| `400 Bad Request` | `urn:mtms:error:invalid-date-range` | Invalid Date Range | `endDate` is prior to `startDate` |
| `404 Not Found` | `urn:mtms:error:branch-not-found` | Branch Not Found | Branch ID does not exist |
| `403 Forbidden` | `urn:mtms:error:forbidden` | Access Forbidden | User does not have branch permissions |
