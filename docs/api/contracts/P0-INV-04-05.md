# API & Data Contract — P0-INV-04 & P0-INV-05: Manual Consumption Issue & Moving WAC Posting Engine

- **Task IDs:** P0-INV-04 (Per-branch moving WAC posting) & P0-INV-05 (Manual consumption issue)
- **Related FE:** FE-P0-27 (Manual consumption issue form)
- **Requirements:** BR-INV-02 (Per-branch moving WAC posting), BR-INV-03 (Manual consumption issue)
- **Test Cases:**
  - TC-020: 10kg@100k + 10kg@120k, issue 5kg -> Per-branch WAC=110k, issue value=550k
  - TC-021: Issue more than balance -> Rejected without stock mutation
  - TC-022: Two concurrent issues of last 5kg -> At most 5kg issued, never negative
- **Dependencies:** P0-INV-01 (Catalog & UOM), P0-INV-02 (Balances & Lots), P0-INV-03 (Receipts & Payables)
- **Status:** PROPOSED (Pending Owner Plan Approval)

### 2.2 Create & Post Consumption Issue (TC-020, TC-021, TC-022)
#### `POST /api/v1/branches/{branchId}/inventory/issues`
- **Scope:** `@branchAuth.hasBranchAccess(#branchId, 'MANAGER', 'OWNER', 'EMPLOYEE')`
- **Header:** `Idempotency-Key: <UUID>`
- **Request Body:**
```json
{
  "documentDate": "2026-11-16",
  "documentType": "CONSUMPTION_ISSUE",
  "reason": "Xuất dùng quầy bar pha chế",
  "autoPost": true,
  "lines": [
    {
      "itemId": "9a7e6b52-3210-482a-a53d-27d1487f61c3",
      "issueQuantity": "5.000",
      "lotId": null,
      "notes": "5kg cà phê pha chế"
    }
  ]
}
```

- **Business Behavior & Invariants:**
  1. **TC-021 No Negative Stock Check:**
     - Query `mtms.stock_balances` with row lock `FOR UPDATE` on `(branch_id, item_id)`.
     - If current on-hand `quantity < issueQuantity` (e.g. balance is 4kg, requesting 5kg):
       -> Reject immediately with HTTP `400 Bad Request` / `422 Unprocessable Entity` (`urn:mtms:error:insufficient-stock`).
       -> Zero stock mutation occurs.
  2. **TC-020 Moving WAC Math Invariant:**
     - Snapshots current Moving WAC: `booked_unit_cost = stock_balance.avg_unit_cost` (e.g. 110,000đ/kg).
     - Computes `booked_total = 5.000 * 110,000 = 550,000.00đ`.
     - Updates balance:
       - `new_quantity = 20.000 - 5.000 = 15.000kg`
       - `new_inventory_value = 2,200,000.00 - 550,000.00 = 1,650,000.00đ`
       - `new_avg_unit_cost = 1,650,000 / 15 = 110,000.00đ` (Moving WAC remains 110k on issue!).
     - Deducts lot quantity if `lotId` specified.
  3. **TC-022 Concurrency Invariant:**
     - Pessimistic locking prevents concurrent threads from overdrafting the last remaining stock.
     - At most available stock is deducted; balance NEVER becomes negative.
  4. **Stock Movement Ledger:**
     - Logs `mtms.stock_movements`:
       - `movement_type = 'MANUAL_ISSUE'`
       - `signed_quantity = -5.000`
       - `signed_value = -550000.00`
       - `booked_avg_cost = 110000.00`
       - `source_type = 'STOCK_DOCUMENT'`
       - `source_id = document.id`
- **Response `201 Created`** with full `StockDocumentDto`.

## 3. Strict RFC 7807 Error Code Catalog

| HTTP Status | `type` URI | `title` | Description |
| :--- | :--- | :--- | :--- |
| `400 Bad Request` | `urn:mtms:error:insufficient-stock` | Insufficient Stock | Requested issue quantity exceeds available stock balance (`TC-021`) |
| `400 Bad Request` | `urn:mtms:error:invalid-issue-quantity` | Invalid Issue Quantity | Quantity must be strictly positive (> 0) |
| `409 Conflict` | `urn:mtms:error:document-already-posted` | Document Already Posted | Stock document has already been finalized |
| `404 Not Found` | `urn:mtms:error:document-not-found` | Document Not Found | Stock document ID does not exist |
| `404 Not Found` | `urn:mtms:error:balance-not-found` | Balance Not Found | Item has no stock balance in this branch |
| `403 Forbidden` | `urn:mtms:error:forbidden` | Access Forbidden | User does not have branch permissions |
