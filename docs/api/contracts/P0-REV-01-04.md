  - `P0-REV-01`: Business calendar (`BR-REV-02` / `TC-005`)
  - `P0-REV-02`: Daily revenue report model (`BR-REV-01` / `TC-006`)

- **Business Requirements:**
  - `BR-REV-01`: Record daily revenue aggregated into cash, bank transfer, delivery app NET.
  - `BR-REV-02`: Track open/closed calendar dates per branch; CLOSED days exempt from missing report.
  - `BR-REV-03`: Manager draft/submit, Owner confirm/adjust; versioned corrections with audit reasons.
- **Key Test Cases:**
  - `TC-004`: Open business day with no report rejects monthly close; missing date list returned.
  - `TC-005`: Closed day with no revenue report is exempt from missing date list.
  - `TC-006`: Concurrency/Retry — Submitting or confirming the same daily report twice does not create duplicate active reports or double post.

## 1. Database Schema Migration (Flyway V013)

### File: `database/migrations/V013__create_business_days_and_daily_revenue.sql`

```sql
-- 1. mtms.business_days (Branch Business Calendar & Day Status)
CREATE TABLE mtms.business_days (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    business_entity_id UUID NOT NULL,
    branch_id UUID NOT NULL,
    business_date DATE NOT NULL,
    operation_status VARCHAR(16) NOT NULL DEFAULT 'OPEN',
    close_reason TEXT,
    recorded_by UUID NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT fk_business_days_entity FOREIGN KEY (business_entity_id) REFERENCES mtms.business_entities(id),
    CONSTRAINT fk_business_days_branch FOREIGN KEY (branch_id) REFERENCES mtms.branches(id),
    CONSTRAINT fk_business_days_user FOREIGN KEY (recorded_by) REFERENCES mtms.users(id),
    CONSTRAINT uq_business_days_branch_date UNIQUE (branch_id, business_date),
    CONSTRAINT ck_business_days_status CHECK (operation_status IN ('OPEN', 'CLOSED')),
    CONSTRAINT ck_business_days_close_reason CHECK (operation_status <> 'CLOSED' OR (close_reason IS NOT NULL AND length(trim(close_reason)) > 0))
);

CREATE INDEX idx_business_days_branch_month ON mtms.business_days(branch_id, business_date);

-- 2. mtms.daily_revenue_reports (Aggregated Daily Revenue)
CREATE TABLE mtms.daily_revenue_reports (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    business_entity_id UUID NOT NULL,
    branch_id UUID NOT NULL,
    business_date DATE NOT NULL,
    revision INTEGER NOT NULL DEFAULT 1,
    is_current BOOLEAN NOT NULL DEFAULT TRUE,
    cash_amount NUMERIC(20, 2) NOT NULL DEFAULT 0,
    bank_transfer_amount NUMERIC(20, 2) NOT NULL DEFAULT 0,
    delivery_app_net_amount NUMERIC(20, 2) NOT NULL DEFAULT 0,
    other_adjustment_amount NUMERIC(20, 2) NOT NULL DEFAULT 0,
    total_revenue NUMERIC(20, 2) NOT NULL DEFAULT 0,
    status VARCHAR(24) NOT NULL DEFAULT 'DRAFT',
    submitted_by UUID NOT NULL,
    submitted_at TIMESTAMPTZ,
    confirmed_by UUID,
    confirmed_at TIMESTAMPTZ,
    adjustment_reason TEXT,
    evidence_file_id UUID,
    note TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT fk_daily_revenue_entity FOREIGN KEY (business_entity_id) REFERENCES mtms.business_entities(id),
    CONSTRAINT fk_daily_revenue_branch FOREIGN KEY (branch_id) REFERENCES mtms.branches(id),
    CONSTRAINT fk_daily_revenue_submitted_by FOREIGN KEY (submitted_by) REFERENCES mtms.users(id),
    CONSTRAINT fk_daily_revenue_confirmed_by FOREIGN KEY (confirmed_by) REFERENCES mtms.users(id),
    CONSTRAINT fk_daily_revenue_evidence FOREIGN KEY (evidence_file_id) REFERENCES mtms.evidence_files(id),
    CONSTRAINT uq_daily_revenue_branch_date_revision UNIQUE (branch_id, business_date, revision),
    CONSTRAINT ck_daily_revenue_revision CHECK (revision > 0),
    CONSTRAINT ck_daily_revenue_cash CHECK (cash_amount >= 0),
    CONSTRAINT ck_daily_revenue_bank CHECK (bank_transfer_amount >= 0),
    CONSTRAINT ck_daily_revenue_delivery CHECK (delivery_app_net_amount >= 0),
    CONSTRAINT ck_daily_revenue_total_pos CHECK (total_revenue >= 0),
    CONSTRAINT ck_daily_revenue_total_math CHECK (total_revenue = cash_amount + bank_transfer_amount + delivery_app_net_amount + other_adjustment_amount),
    CONSTRAINT ck_daily_revenue_status CHECK (status IN ('DRAFT', 'SUBMITTED', 'CONFIRMED', 'SUPERSEDED', 'CANCELLED'))
);

CREATE UNIQUE INDEX uq_daily_revenue_current ON mtms.daily_revenue_reports(branch_id, business_date) WHERE is_current;
CREATE INDEX idx_daily_revenue_branch_month ON mtms.daily_revenue_reports(branch_id, business_date, status);
```

## 2. REST Endpoints Specification

### 2.1 Business Calendar API (`P0-REV-01`)

#### `GET /api/v1/branches/{branchId}/business-days`
- **Scope:** `@branchAuth.hasBranchAccess(#branchId)`
- **Query Params:** `startDate` (YYYY-MM-DD), `endDate` (YYYY-MM-DD), `month` (YYYY-MM)
- **Response `200 OK`:**
```json
[
  {
    "id": "c1f2a3b4-c5d6-47e8-b9a0-112233445566",
    "branchId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
    "businessDate": "2026-11-16",
    "operationStatus": "OPEN",
    "closeReason": null,
    "recordedByName": "Quản lý Cửa hàng",
    "createdAt": "2026-11-16T08:00:00Z"
  }
]
```

#### `PUT /api/v1/branches/{branchId}/business-days/{businessDate}`
- **Scope:** `@branchAuth.hasBranchAccess(#branchId)` (Manager or Owner)
- **Request Body:**
```json
{
  "operationStatus": "CLOSED",
  "closeReason": "Nghỉ sửa chữa hệ thống điện nước quầy bar"
}
```
- **Validation:** If `operationStatus == 'CLOSED'`, `closeReason` is mandatory (non-empty).

### 2.2 Daily Revenue Capture API (`P0-REV-02` / `P0-REV-03`)

#### `POST /api/v1/branches/{branchId}/daily-revenue`
- **Scope:** `@branchAuth.hasBranchAccess(#branchId)`
- **Headers:** `Idempotency-Key` (Optional UUID)
- **Request Body:**
```json
{
  "businessDate": "2026-11-16",
  "cashAmount": "3500000.00",
  "bankTransferAmount": "4200000.00",
  "deliveryAppNetAmount": "2100000.00",
  "otherAdjustmentAmount": "0.00",
  "evidenceFileId": "e3b0c442-98fc-1c14-9afbf4c8996fb924",
  "note": "Doanh thu ca ngày thứ Hai",
  "submitImmediately": true
}
```
- **Response `201 Created`:**
```json
{
  "id": "8c9e6679-7425-40de-944b-e07fc1f90ae8",
  "branchId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "businessDate": "2026-11-16",
  "revision": 1,
  "isCurrent": true,
  "cashAmount": "3500000.00",
  "bankTransferAmount": "4200000.00",
  "deliveryAppNetAmount": "2100000.00",
  "otherAdjustmentAmount": "0.00",
  "totalRevenue": "9800000.00",
  "status": "SUBMITTED",
  "submittedByName": "Quản lý Cửa hàng",
  "submittedAt": "2026-11-16T22:00:00Z",
  "confirmedByName": null,
  "confirmedAt": null,
  "adjustmentReason": null,
  "evidenceFileId": "e3b0c442-98fc-1c14-9afbf4c8996fb924",
  "note": "Doanh thu ca ngày thứ Hai"
}
```

#### `GET /api/v1/branches/{branchId}/daily-revenue`
- **Scope:** `@branchAuth.hasBranchAccess(#branchId)`
- **Query Params:** `startDate`, `endDate`, `status`, `page`, `size`
- **Response `200 OK`:** Paginated list of daily revenue reports.

#### `GET /api/v1/branches/{branchId}/daily-revenue/{id}`
- **Scope:** `@branchAuth.hasBranchAccess(#branchId)`
- **Response `200 OK`:** Full report details.

#### `POST /api/v1/branches/{branchId}/daily-revenue/{id}/confirm`
- **Scope:** `@branchAuth.hasBranchAccess(#branchId)` (Owner/Manager role required)
- **Headers:** `Idempotency-Key` (Optional UUID)
- **Request Body (Optional adjustments):**
```json
{
  "adjustmentReason": null
}
```
- **TC-006 Retry Safety:** If already `CONFIRMED`, returns existing record without throwing error or double posting (`200 OK`).

## 3. Strict RFC 7807 Error Code Catalog

| HTTP Status | `type` URI | `title` | Description |
| :--- | :--- | :--- | :--- |
| `400 Bad Request` | `urn:mtms:error:invalid-revenue-math` | Invalid Revenue Math | Total revenue doesn't match sum of components |
| `400 Bad Request` | `urn:mtms:error:missing-close-reason` | Missing Close Reason | Day is marked CLOSED without reason |
| `409 Conflict` | `urn:mtms:error:duplicate-daily-report` | Duplicate Daily Report | An active report already exists for this date |
| `409 Conflict` | `urn:mtms:error:report-already-confirmed` | Report Already Confirmed | Attempt to edit a confirmed report |
| `404 Not Found` | `urn:mtms:error:report-not-found` | Report Not Found | Daily revenue report does not exist |
| `403 Forbidden` | `urn:mtms:error:forbidden` | Access Forbidden | User does not have branch permissions |
