## 1. Domain Model & Business Invariants

### 1.1 Business Invariants (`BR-CAP-01`, `TC-032`, `CAP-INV-01`, `ADR-007`)
1. **Cô lập Chi nhánh & Phân quyền Nhà đầu tư (`P0-CAP-01` / `TC-001`):**
   - Nhà đầu tư (`mtms.investors`) đăng ký theo pháp nhân (`business_entity_id`).
   - Thỏa thuận hợp tác đầu tư (`mtms.investor_agreements`) ký kết gắn chặt với chi nhánh (`branch_id`).
   - **Quyền bảo mật chi nhánh**: Cổ đông ở Chi nhánh A không có quyền truy cập, xem số liệu hay nhận thông tin tại Chi nhánh B (`TC-001`).
   - **Tách biệt quyền truy cập phần mềm**: Quyền lợi tài chính (Financial entitlement) **không** tự động cấp quyền Quản lý (`BRANCH_MANAGER`) hay Chủ quán (`BRANCH_OWNER`) trên hệ thống phần mềm.

2. **Cam kết & Tiến độ Góp vốn (`P0-CAP-02` / `TC-032`):**
   - Cam kết vốn (`mtms.capital_commitments`): Ghi nhận số vốn cam kết góp (`committed_value`) và giá trị phi tiền mặt được công nhận (`recognized_non_cash_value`).
   - Đợt góp vốn thực tế (`mtms.capital_contributions`):
     - Góp tiền mặt/ngân hàng (`CASH`): Bắt buộc chỉ định `account_id` (quỹ tiền mặt hoặc tài khoản ngân hàng chi nhánh). Hệ thống ghi nhận tăng số dư quỹ qua `CashLedgerService.postLedgerEntry` với danh mục `CAP_INJECTION`, nhóm `CAPITAL_FLOW`, luồng `INFLOW`. **Tuyệt đối không ghi nhận vào doanh thu hoạt động kinh doanh (Operating Revenue)!**
     - Góp tài sản (`ASSET`): Liên kết với `mtms.equipment_assets(id)`.
     - Góp công sức/chất xám (`WORK`): Ghi nhận giá trị định giá đã thỏa thuận.
   - **Bất biến TC-032**:
     $$\text{Outstanding Value} = \max\left(0, \text{Committed Value} - \sum \text{Recognized Value}\right)$$
     Ví dụ: Cam kết 100M VND, thực góp 60M VND -> Hệ thống trả về chính xác:
     - `committedValue = 100,000,000`
     - `actualContributed = 60,000,000`
     - `outstandingValue = 40,000,000`

3. **Nguyên tắc Độc lập Tỷ lệ Lợi nhuận vs Tỷ lệ Góp vốn (`P0-CAP-03` / `CAP-INV-01`):**
   - Tỷ lệ hưởng lợi nhuận (`profit_share_ratio` $\in [0, 1]$) được xác lập độc lập theo điều khoản thỏa thuận hợp đồng cổ đông, **không tự động suy diễn từ tỷ lệ vốn góp**.
   - Ví dụ: Nhà đầu tư A đóng 60% vốn, Nhà đầu tư B đóng 40% vốn, nhưng tỷ lệ thỏa thuận hưởng lợi nhuận có thể là 50% - 50% hoặc theo giai đoạn.

4. **Khóa An toàn Tài chính Phase 0 & Cổng G5 (`ADR-007` / `TC-035`):**
   - Trong Phase 0, các điều khoản phân chia lợi nhuận chỉ mang tính chất **THAM CHIẾU / THÔNG TIN (READ-ONLY INFORMATIONAL ONLY)**.
   - **TUYỆT ĐỐI KHÔNG CÓ BẤT KỲ LỆNH CHI TRẢ LỢI NHUẬN THỰC TẾ (DISTRIBUTION PAYOUT) NÀO TRONG PHA 0!** Việc chi trả lợi nhuận thực tế bị khóa chặt cho đến Phase 1 và khi có xác nhận của chuyên gia kế toán/pháp lý độc lập tại cổng kiểm soát G5.
   - Mọi DTO tóm tắt vốn và tỷ lệ lợi nhuận đều bắt buộc đính kèm trường:
     - `isInformationalOnly: true`
     - `disclaimer: "DỮ LIỆU THIẾT LẬP THAM CHIẾU - CHƯA PHÂN PHỐI LỢI NHUẬN THỰC TẾ TRONG PHA 0 (G5 GATE)"`

## 2. Database Schema (Flyway `V026`)

```sql
-- V026: Create investors, agreements, commitments, contributions and profit terms (BR-CAP-01, TC-032, CAP-INV-01)

CREATE TABLE mtms.investors (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    entity_id UUID NOT NULL REFERENCES mtms.business_entities(id),
    display_name VARCHAR(160) NOT NULL,
    contact_phone VARCHAR(30),
    contact_email VARCHAR(120),
    identity_number VARCHAR(50),
    contact_note VARCHAR(255),
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT uq_investors_entity_display_name UNIQUE (entity_id, display_name)
);

CREATE TABLE mtms.investor_agreements (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    investor_id UUID NOT NULL REFERENCES mtms.investors(id) ON DELETE RESTRICT,
    branch_id UUID NOT NULL REFERENCES mtms.branches(id) ON DELETE RESTRICT,
    agreement_ref VARCHAR(120) NOT NULL,
    contribution_type VARCHAR(20) NOT NULL CHECK (
        contribution_type IN ('CASH', 'ASSET', 'WORK', 'MIXED')
    ),
    effective_from DATE NOT NULL,
    effective_to DATE,
    status VARCHAR(20) NOT NULL DEFAULT 'ACTIVE' CHECK (
        status IN ('ACTIVE', 'TERMINATED', 'EXPIRED')
    ),
    eligibility_terms TEXT,
    evidence_file_id UUID REFERENCES mtms.evidence_files(id),
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT ck_agreement_date_range CHECK (effective_to IS NULL OR effective_to >= effective_from),
    CONSTRAINT uq_agreement_branch_ref UNIQUE (branch_id, agreement_ref)
);

CREATE TABLE mtms.capital_commitments (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    agreement_id UUID NOT NULL REFERENCES mtms.investor_agreements(id) ON DELETE RESTRICT,
    committed_value NUMERIC(22, 2) NOT NULL DEFAULT 0 CHECK (committed_value >= 0),
    recognized_non_cash_value NUMERIC(22, 2) NOT NULL DEFAULT 0 CHECK (recognized_non_cash_value >= 0),
    commitment_due_date DATE,
    status VARCHAR(24) NOT NULL DEFAULT 'PENDING' CHECK (
        status IN ('PENDING', 'PARTIALLY_FULFILLED', 'FULFILLED', 'CANCELLED')
    ),
    notes TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE mtms.capital_contributions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    commitment_id UUID NOT NULL REFERENCES mtms.capital_commitments(id) ON DELETE RESTRICT,
    contributed_on DATE NOT NULL,
    contribution_type VARCHAR(20) NOT NULL CHECK (
        contribution_type IN ('CASH', 'ASSET', 'WORK')
    ),
    recognized_value NUMERIC(22, 2) NOT NULL DEFAULT 0 CHECK (recognized_value > 0),
    account_id UUID REFERENCES mtms.financial_accounts(id),
    asset_id UUID REFERENCES mtms.equipment_assets(id),
    ledger_entry_id UUID REFERENCES mtms.cash_ledger_entries(id),
    evidence_file_id UUID REFERENCES mtms.evidence_files(id),
    notes VARCHAR(255),
    created_by UUID NOT NULL REFERENCES mtms.users(id),
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT ck_contribution_cash_account CHECK (contribution_type != 'CASH' OR account_id IS NOT NULL)
);

CREATE TABLE mtms.profit_entitlement_terms (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    agreement_id UUID NOT NULL REFERENCES mtms.investor_agreements(id) ON DELETE RESTRICT,
    effective_from DATE NOT NULL,
    effective_to DATE,
    profit_share_ratio NUMERIC(9, 6) NOT NULL CHECK (
        profit_share_ratio >= 0 AND profit_share_ratio <= 1
    ),
    eligibility_conditions TEXT,
    approved_by UUID NOT NULL REFERENCES mtms.users(id),
    evidence_file_id UUID REFERENCES mtms.evidence_files(id),
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT ck_profit_terms_dates CHECK (effective_to IS NULL OR effective_to >= effective_from)
);

CREATE INDEX idx_investor_agreements_branch ON mtms.investor_agreements(branch_id, status);
CREATE INDEX idx_capital_commitments_agreement ON mtms.capital_commitments(agreement_id, status);
CREATE INDEX idx_capital_contributions_commitment ON mtms.capital_contributions(commitment_id, contributed_on);
CREATE INDEX idx_profit_terms_effective ON mtms.profit_entitlement_terms(agreement_id, effective_from, effective_to);
```

## 3. REST API Specification

### 3.1 Investor Management
- `GET /api/v1/entities/{entityId}/investors`: Danh sách nhà đầu tư của pháp nhân.
- `POST /api/v1/entities/{entityId}/investors`: Thêm mới nhà đầu tư.

### 3.2 Agreements & Commitments (Branch Scoped)
- `GET /api/v1/branches/{branchId}/capital/agreements`: Danh sách hợp đồng thỏa thuận đầu tư theo chi nhánh.
- `POST /api/v1/branches/{branchId}/capital/agreements`: Tạo hợp đồng thỏa thuận mới gắn với chi nhánh.
- `GET /api/v1/branches/{branchId}/capital/commitments`: Danh sách cam kết góp vốn theo chi nhánh.
- `POST /api/v1/branches/{branchId}/capital/commitments`: Đăng ký cam kết vốn theo thỏa thuận.
- `POST /api/v1/branches/{branchId}/capital/commitments/{id}/contributions`: Ghi nhận đợt góp vốn thực tế (liên kết sổ quỹ nếu CASH).

### 3.3 Profit Terms Viewer & Capital Summary
- `GET /api/v1/branches/{branchId}/capital/profit-terms`: Danh sách tỷ lệ chia lợi nhuận hiệu lực theo hợp đồng.
- `POST /api/v1/branches/{branchId}/capital/profit-terms`: Thiết lập tỷ lệ chia lợi nhuận mới kèm căn cứ phê duyệt.
- `GET /api/v1/branches/{branchId}/capital/summary`: Tổng hợp tình hình vốn:
  - `totalCommittedValue`: Tổng vốn cam kết.
  - `totalActualContributed`: Tổng vốn thực góp.
  - `totalOutstandingValue`: Tổng số vốn còn nợ lại (`TC-032`).
  - `investorCount`: Số lượng nhà đầu tư/cổ đông.
  - `isInformationalOnly: true`: Cờ an toàn Phase 0.
  - `disclaimer`: Thông điệp khóa cổng G5.
  - `investorBreakdowns`: Danh sách đối chiếu từng cổ đông giữa `% Vốn thực góp` vs `% Tỷ lệ lợi nhuận thỏa thuận` (`CAP-INV-01`).
