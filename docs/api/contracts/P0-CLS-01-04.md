## 1. Domain Model & Business Invariants

### 1.1 Business Invariants (`BR-CLS-01`, `BR-CLS-02`, `TC-016`, `TC-040`, `TC-041`)
1. **Kiểm tra Điều kiện Tiên quyết Chốt sổ (`P0-CLS-01` / `TC-040`):**
   - Chốt sổ tháng (`month_start` là ngày đầu tháng, ví dụ: `2026-11-01`) yêu cầu:
     - 100% ngày hoạt động theo lịch chi nhánh trong tháng (`mtms.business_days`) đều đã có Báo cáo Doanh thu ở trạng thái `CONFIRMED` (hoặc là ngày nghỉ `CLOSED` có lý do theo `TC-005`).
     - Bảng lương của chi nhánh trong tháng (`mtms.payroll_periods`) bắt buộc phải ở trạng thái `APPROVED` bởi Chủ quán (`TC-017`).
   - Nếu còn bất kỳ ngày mở cửa nào thiếu báo cáo doanh thu hoặc bảng lương đang ở trạng thái `DRAFT` (hoặc chưa khởi tạo), hệ thống **từ chối lệnh chốt sổ** với mã lỗi RFC 7807 `400 Bad Request` (`urn:mtms:error:closing-prerequisite-failed`).

2. **Báo cáo P&L Quản trị theo Cơ sở Dồn tích vs Dòng tiền (`P0-CLS-02` / `TC-016`):**
   - **Doanh thu thuần (Net Revenue)**: Tổng doanh thu từ các báo cáo doanh thu ngày đã xác nhận (`REV_CASH` + `REV_BANK` + `REV_APP_NET`).
   - **Giá vốn hàng bán (COGS)**: Tổng giá trị xuất kho tiêu hao nguyên vật liệu trong tháng theo phương pháp Moving WAC (`CONSUMPTION_ISSUE`, đã kiểm chứng cân đối kế toán `TC-020`).
   - **Lợi nhuận gộp (Gross Profit)**: $\text{Gross Profit} = \text{Net Revenue} - \text{COGS}$.
   - **Chi phí nhân sự trích trước (Payroll Accrual)**: Tổng lương phát sinh trong tháng từ `mtms.payroll_periods`, **kể cả trường hợp thanh toán tiền mặt/ngân hàng vào tháng kế tiếp** (`TC-016`).
   - **Chi phí vận hành khác (OPEX)**: Tổng các chi phí mặt bằng, điện nước, vật dụng, tiếp thị... từ `mtms.expenses`.
   - **Chi phí thuế (Tax Obligations)**: Các nghĩa vụ thuế đã phân bổ/phát sinh cho chi nhánh trong kỳ từ `mtms.entity_tax_obligations`.
   - **Lợi nhuận kinh doanh tạm tính (Provisional Operating Profit)**: $\text{Gross Profit} - \text{Payroll Accrual} - \text{OPEX} - \text{Tax}$.
   - **Bảng đối chiếu Dòng tiền (Accrual vs Cash Flow Comparison)**: So sánh Lợi nhuận tạm tính với Dòng tiền thuần từ Sổ quỹ (`mtms.cash_ledger_entries`), giải trình rõ các khoản chênh lệch (công nợ nợ NCC chưa trả, tiền App chưa về tài khoản ngân hàng, lương trích trước chưa thanh toán).
   - **Huy hiệu bắt buộc**: Luôn gắn nhãn **"TẠM TÍNH / PROVISIONAL"** và công bố rõ ràng: *"P0 P&L excludes depreciation (TC-051 / ADR-023). Chưa trích khấu hao tài sản vào chi phí."*

3. **Snapshot Bất biến & Khóa Kỳ Đã Chốt (`P0-CLS-03` / `TC-041`):**
   - Khi Chủ quán (`BRANCH_OWNER` / `SYSTEM_ADMIN`) chốt sổ:
     - Tạo bản ghi `mtms.monthly_closes` với `status = 'CLOSED'`, `closed_by`, `closed_at`.
     - Lưu toàn bộ cấu trúc P&L thành JSONB snapshot bất biến.
     - Sinh các dòng chi tiết `mtms.close_components` (`REVENUE_TOTAL`, `COGS_TOTAL`, `GROSS_PROFIT`, `PAYROLL_ACCRUAL`, `OPEX_TOTAL`, `TAX_OBLIGATIONS`, `MANAGERIAL_NET_PROFIT`, `CASH_NET_FLOW`).
   - Sau khi đã `CLOSED`, Quản lý chi nhánh (`BRANCH_MANAGER`) **KHÔNG THỂ** sửa đổi báo cáo doanh thu ngày, bảng lương, xuất kho hồi tố hay chi phí của tháng đó. Hệ thống trả về `409 Conflict` (`urn:mtms:error:closed-period-locked`).

## 2. Database Schema (Flyway `V025`)

```sql
-- V025: Create monthly closes and close components for P0-CLS-01..04 (BR-CLS-01, BR-CLS-02, TC-016, TC-040, TC-041)

CREATE TABLE mtms.monthly_closes (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    branch_id UUID NOT NULL REFERENCES mtms.branches(id),
    month_start DATE NOT NULL,
    revision INTEGER NOT NULL DEFAULT 1 CHECK (revision > 0),
    is_current BOOLEAN NOT NULL DEFAULT TRUE,
    status VARCHAR(28) NOT NULL DEFAULT 'OPEN' CHECK (
        status IN ('OPEN', 'CLOSING', 'CLOSED', 'REOPEN_REQUESTED', 'REOPENED', 'SUPERSEDED')
    ),
    managerial_profit NUMERIC(22, 2),
    is_provisional BOOLEAN NOT NULL DEFAULT TRUE,
    closed_by UUID REFERENCES mtms.users(id),
    closed_at TIMESTAMPTZ,
    snapshot JSONB,
    note TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT uq_monthly_closes_branch_month_rev UNIQUE (branch_id, month_start, revision),
    CONSTRAINT ck_monthly_closes_month_start_first_day CHECK (EXTRACT(DAY FROM month_start) = 1)
);

CREATE UNIQUE INDEX uq_monthly_closes_current 
    ON mtms.monthly_closes (branch_id, month_start) 
    WHERE is_current;

CREATE INDEX idx_monthly_closes_branch_status 
    ON mtms.monthly_closes (branch_id, status);

CREATE TABLE mtms.close_components (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    monthly_close_id UUID NOT NULL REFERENCES mtms.monthly_closes(id) ON DELETE CASCADE,
    component_code VARCHAR(50) NOT NULL,
    signed_amount NUMERIC(22, 2) NOT NULL,
    provenance JSONB NOT NULL DEFAULT '{}'::jsonb,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT uq_close_components_close_code UNIQUE (monthly_close_id, component_code),
    CONSTRAINT ck_close_components_code CHECK (
        component_code IN (
            'REVENUE_TOTAL',
            'REVENUE_CASH',
            'REVENUE_BANK',
            'REVENUE_APP_NET',
            'COGS_TOTAL',
            'GROSS_PROFIT',
            'PAYROLL_ACCRUAL',
            'OPEX_TOTAL',
            'TAX_OBLIGATIONS',
            'MANAGERIAL_NET_PROFIT',
            'CASH_NET_FLOW',
            'ACCRUAL_CASH_VARIANCE'
        )
    )
);

CREATE INDEX idx_close_components_close_id 
    ON mtms.close_components (monthly_close_id);
```

## 4. RFC 7807 Problem Details

| HTTP Status | Type URI | Title | Detail Ví dụ |
| :--- | :--- | :--- | :--- |
| `400 Bad Request` | `urn:mtms:error:closing-prerequisite-failed` | Closing Prerequisite Failed | Không thể chốt sổ kỳ 2026-11-01 do còn 1 ngày chưa nộp doanh thu hoặc bảng lương chưa duyệt. |
| `409 Conflict` | `urn:mtms:error:month-already-closed` | Month Already Closed | Kỳ kinh doanh tháng 2026-11-01 đã được chốt sổ trước đó. |
| `409 Conflict` | `urn:mtms:error:closed-period-locked` | Closed Period Locked | Kỳ kinh doanh tháng 2026-11-01 đã chốt sổ (CLOSED); cấm mọi thao tác sửa đổi doanh thu/lương/chi phí. |
| `403 Forbidden` | `urn:mtms:error:forbidden` | Access Denied | Chỉ Chủ quán (BRANCH_OWNER) mới có quyền thực hiện chốt sổ tháng. |
